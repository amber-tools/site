How to use it

About ten minutes, once. You need Node.js 18 or newer and access to your company's Confluence.

  1. Install the tool

    $ npm i -g amber-tools/confluence-markdown

  2. Tell it where your wiki is

    Create the file ~/.config/amber/config.toml with your wiki's address:

    [confluence]
url = "https://wiki.yourcompany.com"

  3. Save your token

    In Confluence: your avatar → Settings → Personal Access Tokens → Create token. Copy it, then store it in your keychain (macOS asks you to paste it):

    $ security add-generic-password -s amber-confluence-token -a amber -w

    No tokens in your Confluence (versions before Data Center 7.9)? Add user = "you@yourcompany.com" to the config file and store your password instead:

    $ security add-generic-password -s amber-confluence -a you@yourcompany.com -w

    On Linux and Windows, put the token in AMBER_CONFLUENCE_TOKEN in the agent settings in step 5.

  4. Check that it works

    Open any page in your browser and copy its address:

    $ amber confluence doctor "https://wiki.yourcompany.com/pages/viewpage.action?pageId=123"

    Every line should get a tick. The check only reads; it never changes the page.

  5. Connect your agent

    Claude Code:

    $ claude mcp add confluence -- amber-confluence-mcp

    Claude Desktop, Cursor, VS Code and other MCP clients: add this to the MCP settings and restart the app.

    { "mcpServers": { "confluence": { "command": "amber-confluence-mcp" } } }

    If the app says it cannot find the command, run which amber-confluence-mcp and put the full path it prints in place of amber-confluence-mcp.

  6. Add the skill

    Get the agent skill on Agensi and connect Agensi to your agent (one-minute setup). The skill teaches your agent to edit pages safely: which tool to use, how to keep macros, what to do when a colleague edited the page first.

  7. Ask

    Paste a page link and say what to change:

    Use my Agensi skill Amber Confluence. On https://wiki.yourcompany.com/pages/viewpage.action?pageId=123 change the support SLA from 4 hours to 2 hours.

    Then open the page history in Confluence: one new version, with a comment saying what changed.

For developers: the MCP server and the command line

The tool is free and open source. It runs as an MCP server for agents and as a command line tool for people. Anything Markdown cannot express is lifted out before the conversion and put back unchanged; the agent sees a marker in its place. 

{
  "mcpServers": {
    "confluence": {
      "command": "amber-confluence-mcp",
      "env": { "AMBER_CONFLUENCE_URL": "https://wiki.example.com" }
    }
  }
}
